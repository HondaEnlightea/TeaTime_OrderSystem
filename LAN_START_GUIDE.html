ティータイム同好会オーダーシステム · Windows用

このPCをLAN親機にする

親機は、注文・売上を保存し、会計や番号表示の端末へ共有するPCです。この手順で、TeaTimeのフォルダーを受け取った方のPCを親機にできます。作成者のPCは不要です。

上から順に進めてください。コマンドは「コピー」を押し、ターミナルへ貼り付けて実行します。このHTML自体は手順書で、自動的にインストールや起動を行うものではありません。

1Node.jsを入れる

24.14以降の24系を使います。既に導入済みなら再インストールは不要です。手順2へ進み、手順3でバージョンを確認してください。

Windows x64版を入手 Windows ARM64版を入手

Node.js公式の24.22.0インストーラーです。一般的なIntel / AMDのWindows PCはx64、ARM搭載PCはARM64です。種類は「設定 → システム → バージョン情報 → システムの種類」で確認できます。

  1. ダウンロードした .msi を開き、画面の案内に沿ってインストールします。管理者の承認を求められたら、このPCの所有者が確認してください。
  2. 追加のネイティブ開発ツール（Tools for Native Modules）は、このアプリには不要です。
  3. インストール前からターミナルを開いていた場合は、閉じて開き直します。

別バージョンを探す場合：公式の24系一覧。このアプリは22系・25系・26系には対応していません。

2TeaTimeのフォルダーを用意する

  1. 受け取ったZIPをすべて展開し、このPCの書き込み可能な場所へ置きます。ZIPの中から直接実行しません。
  2. server.mjs と public・lib・config フォルダーがあることを確認します。このHTMLだけではシステムは動きません。
  3. 新規導入では、配布元の注文を引き継がないよう data・backups を含まない一式を受け取ります。保存先はこのPCの初回起動時に作られます。既に営業で使っているフォルダーのデータは削除しないでください。

このPCが注文と売上の保存先になります。別の会計端末へソースコードを配る必要はありません。

3ターミナルを開いてLAN起動する

  1. エクスプローラーでTeaTimeのフォルダーを開き、server.mjs が見えている状態にします。
  2. ファイルやフォルダーの上ではなく、一覧の空白部分を右クリックします。
  3. メニューから「ターミナルで開く」を選びます。

開いたターミナルで、下の①と②を順番に実行します。PowerShell・コマンドプロンプトのどちらでも同じコマンドを使えます。貼り付けは Ctrl + V、実行は Enter です。

v24.14.0以降の24系（例：v24.22.0）なら次へ進みます。

URLと「停止: Ctrl+C」が出たら起動完了です。手順4へ進みます。このターミナルは、営業が終わるまで開いたままにしてください。npm install・.cmd・.ps1は使いません。

Windowsからネットワークへのアクセス確認が出る場合は、親機PCの所有者が営業で使うネットワークへの受信許可を確認してください。

「ターミナルで開く」が見つからない場合

スタートメニューで「PowerShell」を検索して開きます。次の例のフォルダーの場所を、このPCの server.mjs があるフォルダーの実際の場所に置き換えて入力してください。

cd "C:\実際の場所\TeaTime_OrderSystem"

Enterを押して移動したら、上の①と②を実行します。フォルダー名に空白があってもよいよう、場所は半角の二重引用符 " で囲みます。

4親機と会計端末で画面を開く

このPC（新しい親機）で使う画面

以下は既定ポート3000の場合です。変更している場合は起動案内のURLを使います。

  • 端末用入口を開く
  • キッチン・お渡しを開く
  • 番号表示・音声準備を開く
  • 注文・会計を開く

別の会計PC・スマートフォンで使う画面

  1. 親機と同じテザリング・Wi-Fi・有線LANへ接続します。
  2. 親機のターミナルに出た「別の端末で開くリンク」→「端末用入口」のURLを、会計端末のブラウザで開きます。複数の候補が出たら、会計端末と同じネットワークのものを使います。
  3. 「接続できました」を確認し、「注文・会計へ」を選びます。

会計端末にはNode.jsの導入もサーバー起動も不要です。番号表示を3台目に分ける場合も同じ入口から進み、音声は番号表示用PCだけで開始します。

別端末で 127.0.0.1 は使いません。親機のIPはPCや接続先によって変わるので、起動案内に出た値を使います。

5営業中・終了・次回の起動

  • 親機は電源につなぎ、電源を切らず・スリープさせず、ターミナルを開いたまま使います。
  • 終了前に各会計端末で未同期0件を確認し、「管理 → 営業設定 → この端末を同期・利用終了」を実行します。その後、最終CSV・バックアップを保存します。
  • 親機のターミナルで Ctrl + C を押します。コマンドを入力できる表示に戻ったら、ターミナルを閉じて構いません。
  • 次回は同じTeaTimeフォルダーで「ターミナルで開く」を選び、node .\server.mjs --lan を実行します。Node.jsの再インストールは不要です。
起動・接続できない場合
  • 「nodeが見つからない」：Node.jsのインストールを確認し、ターミナルを閉じて開き直します。
  • 「server.mjsが見つからない」：そのファイルが見えるフォルダーで、空白部分を右クリックして「ターミナルで開く」を選び直します。
  • 「ポートが使用中」：既に起動しているTeaTimeを確認します。同じPCで二重に起動しません。
  • 「SQLite is an experimental feature」：URLが表示されて使えていれば、この警告だけで起動失敗ではありません。
  • 別端末だけ接続できない：同じネットワーク・正しい親機IP・受信許可を確認します。学校Wi-Fiで端末間通信が遮断される場合は、確認済みのテザリングなどを使います。
  • Node.js自体がブロックされる：このPCの所有者・管理者に利用可否を確認します。HTMLへまとめてもPC側の制限は変わりません。
